# dbt-Airflow-Snowflake-Project
Modern Data Engineering Stack
End-to-end data engineering workflow built with dbt, Snowflake, and Apache Airflow. It focuses on building a structured and scalable pipeline for data ingestion, transformation, and workflow orchestration.

Tech Stack


dbt Core – Used for data transformation, modeling, and data quality
Snowflake – Cloud-based data warehouse for storing and processing data
Apache Airflow – Used to schedule, manage, and orchestrate pipeline workflows
Python – Used for scripting, automation, and data processing
Git – Used for source control and project versioning
